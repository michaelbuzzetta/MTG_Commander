# Deck Collection Update — 2026-09-17

This gameplay release adds a dedicated Deck Collection page reachable from the home screen through **View / Edit Decks**.

## Included behavior

- View every currently available playable Commander deck in one collection.
- Search by deck name or commander.
- Open a deck to inspect its commander, card-type summary, and complete 100-card list.
- Edit any available deck by opening the existing Arena-style deck builder preloaded with its commander and 99-card main deck.
- Delete custom decks from browser storage with confirmation.
- Delete included decks by hiding them locally, preserving the shipped source database.
- Restore all locally deleted included decks from the collection toolbar.
- Select **Use This Deck** from the detail view to return to the home screen with that deck selected.
- Build a new deck directly from the collection page.

Editing an included deck creates a local custom replacement and hides the packaged original. Editing a custom deck updates the existing saved deck instead of creating a duplicate.
